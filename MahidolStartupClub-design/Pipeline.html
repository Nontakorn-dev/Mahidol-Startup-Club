ผู้ใช้พิมพ์

02 · Edge Function
DeepSeek แปลงเจตนา
บังคับตอบเป็น JSON ตาม schema (ดูตัวอย่างด้านล่าง)
03
Query builder
JSON → Supabase: tag, ประเภท, วันปิดรับ, บทบาทที่ขาด
04
จัดอันดับ + เหตุผล
คะแนน match จากกฎ แล้วให้ DeepSeek เขียน “แนะนำเพราะ”
05
แสดงผล

• เรียก DeepSeek จาก Supabase Edge Function — เก็บ API key ฝั่ง server, ใช้ endpoint แบบ OpenAI-compatible + โหมด JSON
• ค่าใน JSON ต้องมาจากรายการที่มีอยู่ — ส่ง tag_options (ตาราง msc-tags เดิม) ไปใน prompt ให้เลือกเท่านั้น ห้ามคิด tag ใหม่
• คำเวลาแบบไทย (“ปิดเทอม”, “เทอมหน้า”) แปลงเป็นช่วงวันจากปฏิทินมหาวิทยาลัยฝั่ง server
• แคชผล parse ตามข้อความที่ normalize แล้ว และ fallback เป็น full-text search เมื่อ confidence ต่ำ
• Semantic search (ถ้าต้องการ) — ใช้ embedding model แยก + pgvector; ตรวจก่อนว่า DeepSeek มี embedding API ให้ใช้หรือยัง
